# Ahora Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans; native implementation followed by independent review.

**Goal:** Deliver the approved continuous-news home and a more frequent efficient collection schedule.
**Architecture:** Existing static app/state and atomic generation refresh; pure selection helpers plus compact DOM rendering; opt-in conditional RSS fetch in the Python collector.
**Tech Stack:** Plain JS/CSS, Python 3.12, existing Node/unittest/Playwright.
**Spec:** docs/superpowers/specs/2026-11-01-ahora-design.md

## Global constraints
Visible Radar RSS identity, backward-compatible #inicio, local preferences, no new runtime dependency or automatic deployment. Schedule 15 minutes; browser check 60 seconds, foreground only. Preserve storage/retention/UID/GUID, TLS and SSRF controls.

## Review focus
Missing/future publication dates must not look freshly published; false cross-feed 304 must not erase news; new generations must not jump reading/focus; local category changes and hidden sources must apply; enlarged text/mobile/keyboard must remain usable.
