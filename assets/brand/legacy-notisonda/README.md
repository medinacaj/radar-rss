# Archivo histórico de NotiSonda (no publicado)
Estos archivos originales se conservan byte a byte para trazabilidad y preservación del diseño proporcionado por el usuario. No forman parte del sitio GitHub Pages, que solo publica `web/`.

Sus anteriores rutas dentro de `web/` sirven los símbolos y tarjetas actuales de Radar RSS por compatibilidad con enlaces y marcadores antiguos. Ver `tests/test_notisonda_assets.py` para los SHA-256 esperados de cada original y `tests/test_public_brand_identity.py` para las equivalencias públicas.

La cadena de limpieza de caché antigua en `web/sw.js` sigue siendo necesaria para la migración de instalaciones PWA.
