# Radar RSS · Pulso editorial

Identidad actual: símbolo RSS naranja, marca tipográfica condensada y papel cálido. El símbolo maestro fue generado para el proyecto con image_gen; no se afirma exclusividad del símbolo RSS.

Los maestros anteriores se conservan en `archive/`, incluidos los de la etapa azul. La exportación raster se reproduce con `RADAR_CHROMIUM_EXECUTABLE=/usr/bin/chromium python3 browser_tests/export_radar_brand.py` desde la raíz. El recorte fuente conserva la caja útil y el icono maskable añade margen de seguridad sobre fondo oscuro.

`web/fonts/Anton-Regular.ttf` procede de https://raw.githubusercontent.com/google/fonts/main/ofl/anton/Anton-Regular.ttf y se distribuye con `web/fonts/Anton-OFL.txt`. Se sirve localmente, también offline mediante el service worker; no requiere Google Fonts en el navegador. Los datos tipográficos originales no se modifican.
